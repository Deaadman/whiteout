## Whiteout Core (Muskeg)

The Whiteout Core (Muskeg) is a library built for managing mods for The Long Dark through the [native desktop apps](../clients/). It is built with [Rust](https://rust-lang.org/).

The second name, muskeg is the code name, and is named after [Forlorn Muskeg](https://thelongdark.fandom.com/wiki/Forlorn_Muskeg).
