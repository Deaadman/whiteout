## Whiteout Core (Hibernia)

The Whiteout Core (Hibernia) is a library built for managing mods for The Long Dark through the [website](../../clients/voyageur). It is built with [Rust](https://rust-lang.org/).

The second name, hibernia is the code name, and is named after [Hibernia Processing](https://thelongdark.fandom.com/wiki/Hibernia_Processing).
