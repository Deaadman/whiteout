## Whiteout Core

The Whiteout Core is a library built for managing your The Long Dark mods through the [native desktop apps](../apps/). It is built with [Rust](https://rust-lang.org/).

The name muskeg is the code name, and is named after [Forlorn Muskeg](https://thelongdark.fandom.com/wiki/Forlorn_Muskeg).
