## Whiteout App (Windows)

The Whiteout App is a native desktop application for managing your The Long Dark mods. It is built with [WinUI 3](https://learn.microsoft.com/en-us/windows/apps/winui/winui3/).

The name perseverance is the code name, and is named after [Perseverance Mills](https://thelongdark.fandom.com/wiki/Perseverance_Mills).
